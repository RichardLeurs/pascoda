# Pascoda VLC package

`PascodaVlc.lpk`: `TPascodaVlcPlayer` and `TPascodaVlcListPlayer`, on the VLC library installed in
`/Applications/VLC.app`. Import it with File > Import Component Package... (or Add Pascoda VLC).

The icons `tpascodavlcplayer.png` and `tpascodavlclistplayer.png` are copies of Lazarus's
`tlclvlcplayer.png` and `tvlcmedialistplayer.png` (`components/vlc` in Lazarus). Lazarus's component
icons are under the modified LGPL, see `COPYING.modifiedLGPL.txt` (the same text as
`crates/pascoda-app/assets/`). A package's icon is found by class name next to its `.lpk`.
